# Golden Atomic Brand References (GABR)

The pillar of the brand OS. **Golden** = best-in-class example of its type. **Atomic** = a single self-contained reusable unit. **Brand Reference** = fed back into an image model as in-context reference to generate net-new on-brand assets.

A rulebook tells a model what to do; golden references show it what *good* looks like. Each reference is stored next to the exact prompt that produced it + alt text. References are generated **incrementally, with human validation** — that validation is what makes them "golden."

## Build your set

Drop each validated render here as `gabr-NN-<name>.png` with a sibling `gabr-NN-<name>.prompt.md` (prompt, tool, references, status, alt text). Typical set:

- the **mark**
- a **hero / welcome** scene
- each **mascot**
- your **core content atom**
- key **template exemplars** (e.g. a social cover, a card, a map)
- a **sticker set** (individual atomic stickers beat one combined sheet)

## Disciplines

- **Validate each** with a human before it's golden.
- **Store the prompt next to the output.**
- **Pass references in** for reused elements (mark, mascot) so style never drifts.
- **Stamp the lockup** on finished assets; don't let the model draw the wordmark.
