# Type

Define typefaces by role (display, any accent, body), a web-font source, and a type scale. Ship the font files in `static/brand/fonts/` and point `@font-face` at them in `src/css/custom.css`.

## Scale

| Role | Token | Size |
|------|-------|------|
| Display | `--brand-text-display` | 72px |
| H1 | `--brand-text-h1` | 32px |
| H2 | `--brand-text-h2` | 24px |
| Body | `--brand-text-body` | 18px |

## Pairing rules

Define when to use display vs body, and any accent face. Keep body legible at every size.
