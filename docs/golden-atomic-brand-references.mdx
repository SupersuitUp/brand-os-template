# Golden Atomic Brand References

The pillar of a brand OS. **A rulebook tells a model what to do; golden references show it what good looks like.** These are the canonical exemplar renders that *are* your brand universe — fed back into an image model as in-context references to generate net-new on-brand assets forever.

## How to build your set

Generate the exemplars that ARE your universe — typically: the mark, a hero/welcome scene, each mascot, your core content atom, your key templates (e.g. a social cover, a card), and a sticker set.

1. **Generate incrementally, validating each.** Human validation is what makes a reference "golden." Never batch-generate blind.
2. **Store the prompt next to every render.**
3. **Pass earlier references back in** as input images for any reused element (mark, mascot) so style never drifts.
4. **Always-on lockup** on finished assets: generate art clean with a reserved band, then **stamp the real wordmark PNG** programmatically — image models garble text.
