# Color

Define semantic roles (ground, ink, primary, accent, status) with a hex each in [`tokens.css`](/brand/tokens.css) and mirror them into `src/css/custom.css` `@theme` so Tailwind utilities (`bg-brand-primary`, `text-brand-ink`, …) generate. Ground is rarely pure white — confirm the off-white.

These swatches read from the placeholder tokens — replace them:

:::tip[Tokens are the source of truth]

Add as many roles as your brand needs (status colors, a full accent set). Everything — portal, generated sites, decks — pulls from `tokens.css`.

:::
