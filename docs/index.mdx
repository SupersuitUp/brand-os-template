# Brand OS — Template

This is a **Brand OS template**: the brand as a *system* an agent can read and generate from, not a static PDF. Fork it, run the [`generate-a-brand-os`](https://www.appliedai.wiki/playbooks/generate-a-brand-os) recipe, and replace every `[[PLACEHOLDER]]`.

> Read [`GETTING-STARTED.md`](https://github.com/[[org]]/[[repo]]/blob/main/GETTING-STARTED.md) for the fork → fill workflow.

## The success test

Hand only your filled-in repo to an agent with no designer and ask for a landing page, a deck, and a social set. If the three come back unmistakably one brand, the OS is real.

## The components

1. **[Logo matrix](/logos)** — your mark + wordmark + lockups in every treatment.
2. **[Color](/color)** — your palette as tokens.
3. **[Type](/type)** — display · accent · body.
4. **[Golden Atomic Brand References](/golden-atomic-brand-references)** — the pillar: exemplar renders that seed all net-new assets. Your **motifs** and **template exemplars** live here.
5. **[Generation layer](/generation-layer)** — master prompt, example prompts, banned terms, illustration spec.

Plus the **[voice](/voice)** slice.

## How to consume it

- **Source of truth** is the repo root: `BRAND.md` (read first) + `brand.json` + `tokens.css`.
- The **asset package** lives under `static/brand/` (served at `/brand/...`).
- This portal is the **human gallery** rendered over that package.
